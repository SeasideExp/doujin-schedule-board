# まもなく即売会が参ります (Ver.0.19c)

> **最終更新: 2026年11月17日 ／ 最新バージョン: Ver.0.19c**  
> ※ 各バージョンの詳細な更新履歴は [**`CHANGELOG.md`**](./CHANGELOG.md) をご覧ください。

同人誌即売会などのイベント参加予定と原稿締切を、**駅の発車標風ボード**と**年別・日別カレンダー**の2画面で検討・管理できるブラウザツールです。

---

## 📖 1. 概要

左ペインに駅の発車標を模した時系列スケジュールボード、右ペインに年別・日別のカレンダー＆重複比較パネルを備えています。  
同じ日に複数の即売会が重なった場合の参加可否検討から、原稿締切のカウントダウン、年別の表形式PDFログ出力までを1画面で完結できます。

---

## ✨ 2. 主な機能

- **駅の発車標風ボード（左ペイン）**
  - イベント予定と原稿締切を時系列順に一覧表示し、残り日数（僅少強調・点滅設定・日数範囲調整に対応）をひと目で把握できます。
  - 名称クリックで直接編集でき、種別・状況フィルタ、スクロール表示（電光掲示板風メッセージ）にも対応しています。
- **年別・日別スケジュール管理 ＆ 重複検討（右ペイン）**
  - 月別カレンダー・日別一覧（年間／向こう一年）を切り替え、同日に複数イベントが重なった場合はカードを並べて比較検討できます。
  - 参加状況は `参加` / `参加（未申込）` / `検討` / `不参加` / `一般参加` / `売り子参加` の6種類に対応しています。
- **イベント名・ジャンル名・場所の候補保存**
  - 自由入力に加えて、よく使うイベント名（既定の場所紐付け可）・ジャンル名・会場を「★ 候補に保存」および「候補マスタ」から再利用できます。
- **年別PDFログ出力 ＆ UIカスタマイズ**
  - 発車標のデータを年別のシンプルな表形式PDF（印刷保存）／CSVとして出力できます。
  - 上部経過・締切バー（今日％／今月％／締切カウントダウン）、左右・上下の境界リサイズ、配色カスタマイズ、**JFLY推奨カラーユニバーサルデザイン（CUD）モード**に対応しています。
- **データ保存 ＆ バックアップ**
  - ブラウザ内（`localStorage`）へ自動保存するほか、JSONファイルでの保存・読込（上書き／追加統合）に対応しています。

> [!WARNING]
> **データのバックアップについて**: 作業データはブラウザ内ストレージ（`localStorage`）に自動保存されますが、閲覧データの削除やシークレットウィンドウの終了により失われる場合があります。大切なデータはこまめに **「💾 データ保存 (JSON)」** からローカルへ保存することを推奨します。

## 🚀 3. 動作方法

Webサーバーの構築は不要です。**[`index.html`](./index.html) をWebブラウザ（Chrome / Edge / Firefox / Safari 等）で直接開くだけ（`file://`）**で、オフライン環境でもそのまま動作します。

---

## 📁 4. 構成

```text
doujin-schedule-board/
├── index.html          # UI構造・DOM定義、スクリプト順次読込
├── styles.css          # レイアウト・発車標LED・CUD配色・印刷用PDFスタイル
├── README.md           # プロジェクト解説
├── CHANGELOG.md        # 全バージョンの変更履歴
├── AGENTS.md           # 開発ルール・バージョン管理指示書
└── js/
    ├── state.js        # バージョン管理・状態管理・日付演算・localStorage保存
    ├── settings.js     # UI設定・CUD配色・点滅設定・スクロール表示管理
    ├── presets.js      # イベント名・ジャンル名・場所の候補マスタ管理
    ├── board.js        # 左ペイン発車標描画・時計・上部情報バー更新
    ├── planner.js      # 右ペインカレンダー・日別一覧・重複比較・入力モーダル
    ├── outputs.js      # 年別PDFログ・CSV出力・JSON入出力・サンプルデータ
    └── main.js         # イベント結線・リサイザー・初期化
```
